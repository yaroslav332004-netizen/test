# NOTES

Робочі нотатки проєкту: що було незрозуміло, що довелося шукати, які рішення ухвалено.

## ЛР 1

- Основна відмінність SDK від Runtime: SDK містить компілятор і команду `dotnet`, Runtime лише запускає готові програми.
- Рядок `Console.OutputEncoding = UTF8` потрібен через термінал Windows, який може виводити кирилицю в однобайтовому кодуванні.
- `bin/` і `obj/` не потрапляють у репозиторій, бо їх створює збирання.
